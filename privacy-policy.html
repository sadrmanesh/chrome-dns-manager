🔒 Privacy Policy

DNS Configuration Manager Extension

📋 Overview

This Privacy Policy describes how the DNS Configuration Manager Chrome extension ("we", "our", or "us") handles your information. We are committed to protecting your privacy and ensuring transparency in our data practices.

🛡️ Key Privacy Principles

This extension does not collect, store, or transmit any user data. All operations occur locally in your browser. We believe in complete transparency and minimal data collection.

📊 Data Collection

We collect NO personal information. Our extension operates entirely within your browser and does not:

  • Collect any personal data
  • Store information on external servers
  • Track your browsing activity
  • Send data to third-party services
  • Use analytics or tracking tools

💾 Local Storage

The only data stored is your DNS configuration preferences, which are saved locally in your browser using Chrome's storage API. This includes:

  • Your custom DNS server settings
  • Language preferences
  • Extension state (enabled/disabled)
  • Provider favorites and display preferences

This data remains on your device and is never transmitted to external servers. You may explicitly export saved custom profiles to a local JSON file or import a validated file; profile files are not uploaded by the extension.

🌐 Network Communication

No external network requests: The extension does not make external API or fetch requests. When supported, it reads Chrome-provided connection estimates (RTT, downlink, and network type) only to display them locally; those estimates are not stored or transmitted.

🔐 Permissions

Our extension requires minimal permissions:

  • storage: To save DNS profiles locally

The extension does not request proxy or host permissions and does not change DNS settings.

🔍 Code Transparency

Our extension code is:

  • Fully readable and not minified
  • Open source and transparent
  • Free from obfuscation or encryption
  • Available for public review

🔄 Updates

This Privacy Policy may be updated occasionally. Any significant changes will be communicated through the extension's update process. Continued use of the extension after changes constitutes acceptance of the updated policy.
