🌐 DNS Configuration Manager

Smart DNS management extension for Chrome browser with multilingual support

📋 About This Extension

DNS Configuration Manager stores DNS server profiles. Choose presets, create custom profiles, and copy addresses for manual setup. It does not change DNS settings or test connectivity.

✨ Key Features

🔧 DNS Profile Management

Choose a preset or save a custom DNS server profile for manual configuration.

⚙️ Custom DNS Support

Create and save your own custom DNS configurations with primary and secondary DNS servers.

🌍 Multilingual Support

Fully translated interface in English, Persian (فارسی), Arabic (العربية), and Chinese (中文).

💾 Persistent Settings

Your DNS preferences are automatically saved and restored when you reopen the extension.

⌕ Search and Compare

Search providers and addresses, filter profiles by purpose, and compare up to three options.

☆ Favorites and Backup

Keep preferred providers close and import or export saved profiles with a local JSON file.

📶 Network Estimates

View browser-provided RTT, download, and connection-type estimates when supported. No speed test or game-server ping is performed.

🎮 Gaming DNS Guidance

Understand DNS's role in sign-in and matchmaking lookups; DNS does not reduce latency after a game session is connected.

How the extension works

This is a local profile and reference tool, not a DNS switcher or network benchmark.

  • Profile storage: DNS addresses, favorites, and preferences are kept in Chrome local storage. Choosing a profile does not apply it to Chrome or the operating system.
  • Secure DNS setup: DoH templates and official provider references help with manual setup in Chrome Settings; the extension does not activate a provider or probe its service.
  • Provider comparisons: Categories, published addresses, source links, and known DoH templates are reference data, not measured quality or availability claims.
  • Network and gaming: RTT and downlink values are browser estimates when available. No speed test, resolver query, or game-server ping is run; DNS may affect name resolution before a connection, not in-session game latency.
  • Profile portability: Custom profiles can be exported to a local JSON file and imported after validation. Imports skip duplicates and add profiles without replacing existing data.

📥 Installation Guide

Download the Extension

Download the extension files from the project repository.

Open Chrome Extensions

Go to chrome://extensions/ in your Chrome browser.

Enable Developer Mode

Toggle the "Developer mode" switch in the top right corner.

Load Extension

Click "Load unpacked" and select the extension folder.

Start Using

Click the extension icon in your toolbar to start managing DNS settings.

⚠️ Important Information

DNS profiles only: This extension stores DNS server profiles and lets you copy their addresses. It does not change DNS settings or test DNS connectivity. Network details, when available, are estimates supplied by Chrome, not an active speed test or game-server ping.

🌐 مدیر تنظیمات DNS

افزونه مدیریت هوشمند DNS برای مرورگر کروم با پشتیبانی چندزبانه

📋 درباره این افزونه

این افزونه پروفایل‌های DNS آماده و سفارشی را ذخیره می‌کند و امکان کپی نشانی‌ها برای تنظیم دستی را می‌دهد؛ تنظیمات DNS را تغییر نمی‌دهد. در صورت پشتیبانی، تخمین‌های شبکهٔ ارائه‌شده توسط Chrome را نمایش می‌دهد.

✨ ویژگی‌های کلیدی

🔧 مدیریت پروفایل‌های DNS

پروفایل‌های آماده یا سفارشی را ذخیره کنید و نشانی‌ها را برای تنظیم دستی در کروم یا سیستم کپی کنید.

⚙️ پشتیبانی از DNS سفارشی

تنظیمات DNS دلخواه خود را با سرور اصلی و فرعی بسازید و ذخیره کنید.

🌍 پشتیبانی چندزبانه

رابط کاملاً ترجمه‌شده به فارسی، انگلیسی، عربی و چینی.

💾 ذخیره‌سازی پایدار

تنظیمات DNS شما به طور خودکار ذخیره و هنگام باز کردن مجدد افزونه بازیابی می‌شود.

⌕ جست‌وجو و مقایسه

ارائه‌دهندگان و نشانی‌ها را جست‌وجو کنید، بر اساس کاربرد فیلتر بزنید و حداکثر سه گزینه را مقایسه کنید.

☆ علاقه‌مندی و پشتیبان

ارائه‌دهندگان دلخواه را نشان‌گذاری کنید و پروفایل‌های ذخیره‌شده را با یک فایل JSON محلی درون‌ریزی یا صادر کنید.

📶 تخمین‌های شبکه

در صورت پشتیبانی، تخمین RTT، سرعت دریافت و نوع شبکهٔ ارائه‌شده توسط مرورگر را ببینید؛ آزمون سرعت یا پینگ سرور بازی اجرا نمی‌شود.

🎮 راهنمای DNS برای بازی

DNS ممکن است بر جست‌وجوی نام هنگام ورود یا آغاز مسابقه اثر بگذارد، اما تأخیر پس از اتصال به بازی را کاهش نمی‌دهد.

افزونه چگونه کار می‌کند؟

این افزونه ابزار محلی مدیریت پروفایل و اطلاعات مرجع است؛ DNS را تغییر نمی‌دهد و شبکه را ارزیابی نمی‌کند.

  • ذخیرهٔ پروفایل: نشانی‌های DNS، علاقه‌مندی‌ها و ترجیحات در حافظهٔ محلی Chrome نگهداری می‌شوند. انتخاب پروفایل آن را در Chrome یا سیستم‌عامل اعمال نمی‌کند.
  • راه‌اندازی DNS امن: الگوهای DoH و پیوندهای رسمی برای تنظیم دستی در بخش تنظیمات Chrome هستند؛ افزونه ارائه‌دهنده را فعال نمی‌کند و سرویس را نمی‌آزماید.
  • مقایسهٔ ارائه‌دهندگان: دسته‌بندی‌ها، نشانی‌های منتشرشده، منابع و الگوهای DoH اطلاعات مرجع هستند، نه ادعای کیفیت یا دسترس‌پذیری اندازه‌گیری‌شده.
  • شبکه و بازی: RTT و سرعت دریافت، در صورت پشتیبانی، تخمین‌های مرورگر هستند. آزمون سرعت، درخواست DNS یا پینگ سرور بازی انجام نمی‌شود؛ DNS ممکن است بر جست‌وجوی نام پیش از اتصال اثر بگذارد، نه تأخیر داخل بازی.
  • انتقال پروفایل: پروفایل‌های سفارشی به فایل JSON محلی صادر و پس از اعتبارسنجی درون‌ریزی می‌شوند. موارد تکراری نادیده گرفته می‌شوند و داده‌های قبلی جایگزین نمی‌شوند.

كيف تعمل الإضافة؟

هذه أداة محلية لإدارة الملفات والمعلومات المرجعية، وليست أداة لتغيير DNS أو قياس الشبكة.

  • إعداد DNS الآمن: تساعد قوالب DoH وروابط المزودين الرسمية في الإعداد اليدوي من إعدادات Chrome؛ ولا تفعّل الإضافة مزودًا أو تختبر خدمته.
  • مقارنة المزودين: الفئات والعناوين المنشورة وروابط المصادر وقوالب DoH بيانات مرجعية وليست ادعاءات مقاسة عن الجودة أو التوفر.
  • الشبكة والألعاب: قيم RTT والتنزيل تقديرات من المتصفح عند توفرها. لا يُجرى اختبار سرعة أو استعلام DNS أو ping لخادم لعبة؛ وقد يؤثر DNS في البحث عن الاسم قبل الاتصال لا في زمن الاستجابة أثناء اللعب.
  • نقل الملفات: يمكن تصدير الملفات المخصصة إلى JSON محلي واستيرادها بعد التحقق. تُتجاهل النسخ المكررة وتُضاف الملفات دون استبدال البيانات الحالية.

🌐 DNS配置管理器

适用于Chrome浏览器的智能DNS管理扩展，支持多语言

📋 关于本扩展

此扩展用于保存预设和自定义 DNS 配置，并复制地址以便手动设置；它不会更改 DNS 设置。支持时会显示 Chrome 提供的网络估算值。

✨ 主要功能

🔧 DNS 配置管理

保存预设或自定义配置，并复制地址以便在 Chrome 或操作系统中手动设置。

⚙️ 支持自定义DNS

创建并保存您自己的主/备DNS服务器配置。

🌍 多语言支持

界面已完整翻译为中文、英语、波斯语和阿拉伯语。

💾 持久设置

您的DNS偏好会自动保存，并在重新打开扩展时恢复。

⌕ 搜索与比较

搜索服务商和地址，按用途筛选配置，并比较最多三个选项。

☆ 收藏与备份

收藏常用服务商，并通过本地 JSON 文件导入或导出已保存的配置。

📶 网络估算

支持时可查看浏览器提供的 RTT、下载速度和网络类型估算值；不会进行测速或连接游戏服务器。

🎮 游戏 DNS 说明

DNS 可能影响登录或匹配时的域名查询，但游戏连接建立后不会降低延迟。

扩展的工作方式

这是本地配置管理与参考工具，不会切换 DNS，也不会进行网络测速。

  • 配置存储：DNS 地址、收藏和偏好保存在 Chrome 本地存储中。选择配置不会将其应用到 Chrome 或操作系统。
  • 安全 DNS 设置：DoH 模板和服务商官方链接用于辅助在 Chrome 设置中手动配置；扩展不会启用服务商或探测其服务。
  • 服务商比较：分类、公开地址、来源链接和已知 DoH 模板均为参考信息，不代表经过测量的质量或可用性。
  • 网络与游戏：支持时显示的 RTT 和下载值来自浏览器估算。不会测速、查询解析器或 ping 游戏服务器；DNS 可能影响连接前的域名解析，不会改变游戏连接后的延迟。
  • 配置迁移：自定义配置可导出到本地 JSON 文件，经过校验后导入。重复项会跳过，导入会新增配置而不覆盖现有数据。
