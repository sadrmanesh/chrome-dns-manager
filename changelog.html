DNS Configuration Manager · Release history

📝 Changelog

Product updates, new capabilities, and maintenance changes by version.

Version 1.5.0 2026-10-24

  • Added provider search and use-case filters with official source links, DoH details, and a review date.
  • Added favorites and comparison for up to three profiles.
  • Added local JSON backup for custom profiles with validation and non-overwriting imports.
  • Refined controls, icons, and responsive styling across the popup and supporting pages.

Version 1.4.0 2026-10-24

  • Added 13 free DNS profiles from Cloudflare, AdGuard, CleanBrowsing, and Control D.
  • Expanded the DoH template catalog with filtered and unfiltered options.
  • Added Chrome-provided RTT, downlink, and network-type estimates where supported.
  • Added gaming guidance clarifying DNS's limited effect on in-session latency.

Version 1.3.0 2026-10-24

  • Redesigned the extension popup and supporting pages.
  • Added system, light, and dark appearance options.
  • Added built-in and custom DoH profiles for manual Chrome Secure DNS setup.
  • Improved error handling and corrected repository and author details.

Version 1.2.0 Date not recorded

  • Removed Iranian DNS servers from the default list for security.
  • Added manual entry for DNS servers.
  • Updated documentation and locale files.

Version 1.1.0 Date not recorded

  • Changed the project license to a custom non-commercial license.
  • Added license details and usage terms.

Version 1.0.0 Date not recorded

  • Initial release with DNS profile management and a multilingual interface.

نسخهٔ 1.5.0 2026-10-24

  • افزودن جست‌وجو و فیلتر کاربردی DNS همراه با منابع رسمی، جزئیات DoH و تاریخ بررسی.
  • افزودن علاقه‌مندی‌ها و امکان مقایسهٔ حداکثر سه پروفایل.
  • افزودن پشتیبان‌گیری محلی JSON برای پروفایل‌های سفارشی با اعتبارسنجی و بدون بازنویسی داده‌های موجود.
  • بهبود کنترل‌ها، آیکون‌ها و چیدمان واکنش‌گرا در پنجره و صفحات راهنما.

نسخهٔ 1.4.0 2026-10-24

  • افزودن ۱۳ پروفایل DNS رایگان از Cloudflare، AdGuard، CleanBrowsing و Control D.
  • گسترش الگوهای DoH با گزینه‌های فیلترشده و بدون فیلتر.
  • نمایش تخمین RTT، سرعت دریافت و نوع شبکهٔ ارائه‌شده توسط Chrome، در صورت پشتیبانی.
  • افزودن راهنمای بازی و توضیح محدودیت تأثیر DNS بر تأخیر حین بازی.

نسخهٔ 1.3.0 2026-10-24

  • بازطراحی پنجرهٔ افزونه و صفحات راهنما.
  • افزودن پوسته‌های سیستم، روشن و تیره.
  • افزودن پروفایل‌های DoH آماده و سفارشی برای پیکربندی دستی Secure DNS در Chrome.
  • بهبود مدیریت خطا و اصلاح اطلاعات مخزن و نویسنده.

نسخهٔ 1.2.0 تاریخ ثبت نشده

  • حذف DNSهای ایرانی از فهرست پیش‌فرض به دلایل امنیتی.

نسخهٔ 1.1.0 تاریخ ثبت نشده

نسخهٔ 1.0.0 تاریخ ثبت نشده

الإصدار 1.5.0 2026-10-24

  • إضافة المفضلة ومقارنة ما يصل إلى ثلاثة ملفات تعريف.
  • إضافة نسخ احتياطي محلي بصيغة JSON للملفات المخصصة مع التحقق ودون استبدال البيانات الموجودة.

الإصدار 1.4.0 2026-10-24

  • توسيع قوالب DoH بخيارات التصفية وبدون تصفية.
  • إضافة تقديرات RTT والتنزيل ونوع الشبكة التي يوفرها Chrome عند توفرها.
  • إضافة إرشادات للألعاب توضّح محدودية تأثير DNS في زمن الاستجابة أثناء اللعب.

الإصدار 1.3.0 2026-10-24

  • إضافة خيارات المظهر: النظام والفاتح والداكن.
  • إضافة ملفات DoH جاهزة ومخصصة لضبط Secure DNS في Chrome يدويًا.
  • تحسين معالجة الأخطاء وتصحيح بيانات المستودع والمؤلف.

الإصدار 1.1.0 التاريخ غير مسجل

版本 1.5.0 2026-10-24

  • 新增服务商搜索和用途筛选，展示官方来源、DoH 信息及核验日期。
  • 新增收藏功能，并支持比较最多三个配置。
  • 新增自定义配置的本地 JSON 备份，导入时进行校验且不会覆盖现有配置。
  • 优化弹出窗口和配套页面的控件、图标及响应式布局。

版本 1.4.0 2026-10-24

  • 新增来自 Cloudflare、AdGuard、CleanBrowsing 和 Control D 的 13 个免费 DNS 配置。
  • 扩展 DoH 模板目录，包含过滤和无过滤选项。
  • 在支持时显示 Chrome 提供的 RTT、下载速度和网络类型估算值。
  • 添加游戏说明，明确 DNS 对游戏会话内延迟的有限影响。

版本 1.3.0 2026-10-24

  • 重新设计扩展弹出窗口和配套页面。
  • 新增系统、浅色和深色外观选项。
  • 新增用于手动配置 Chrome 安全 DNS 的预设和自定义 DoH 配置。
  • 改进错误处理并更正仓库与作者信息。

版本 1.2.0 日期未记录

  • 出于安全原因，从默认列表中移除伊朗 DNS 服务器。
  • 支持手动添加 DNS 服务器。
  • 更新文档和语言文件。

版本 1.1.0 日期未记录

  • 将项目许可证更改为自定义非商业许可证。
  • 增加许可证详情和使用条款。

版本 1.0.0 日期未记录

  • 首次发布，提供 DNS 配置管理和多语言界面。
